# Lets Revanced
Lets es una aplicacion para dispositivos Android que busca  la recuperación de la comunicación verbal de personas con Síndrome de Cautiverio mediante el uso de gestos oculares.
## ¿Como funciona?
Funciona mediante el uso de MediaPipe Face Landmarker, OpenCV y un algoritmo de comparación con plantillas calibradas del usuario.
